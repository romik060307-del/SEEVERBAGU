RKM SERVER v1.3.0 — PANDUAN API SERVER
====================================

Semua contoh memakai URL dasar http://HOST:8080. Ganti HOST dengan IP tablet atau domain tunnel. TOKEN didapat dari hasil /api/login atau /api/register. Request POST mengirim JSON Content-Type: application/json.

KONDISI PENTING
---------------
Ini API server. Klien web/aplikasi tetap perlu memanggil API dan menggambar antarmukanya. File HTML lama tidak ikut diubah. Endpoint live di bawah menyimpan metadata, bukan mengirim aliran video/audio; Google Drive membutuhkan OAuth dari klien.
